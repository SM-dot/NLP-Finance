This folder is self-contained: run the scripts in order to rebuild the dataset from scratch,
then run `analysis.ipynb` for the exhibits and write-up. No data files are checked into
git — `data/` is gitignored, per the assignment's instructions.

## Pipeline

| Script | What it does | Time |
|---|---|---|
| `scripts/01_collect_documents.py` | Scrapes FOMC statements, minutes, Chair speeches, testimony and press conference transcripts from federalreserve.gov, Feb 2018 - present | ~5 min |
| `scripts/02_market_data.py` | Downloads DXY, the 10s2s spread, the 1-year yield, Russell 1000 Growth/2000 Value, and the 3-month bill (control) | ~1 min |
| `scripts/03_score_wordlist.py` | Scores every document with the custom hawkish/dovish word list | ~1 s |
| `scripts/04_score_finbert.py` | Scores every document with FinBERT (ProsusAI/finbert), sentence by sentence | ~4 min (Apple Silicon GPU via MPS) |
| `scripts/05_build_dataset.py` | Merges tone scores with the one-day market reaction to each release | ~5 s |

```bash
pip install -r requirements.txt
cd scripts
python 01_collect_documents.py
python 02_market_data.py
python 03_score_wordlist.py
python 04_score_finbert.py
python 05_build_dataset.py
```

Then open `analysis.ipynb`.

## Data and methods

- **Sample window.** February 5, 2018 (Jerome Powell sworn in) through September 15, 2026
  (the day this assignment is due — one day before the September FOMC decision, which is
  why the forecast in the report is a genuine forecast and not a lookup).
- **Chair transition.** Kevin Warsh was sworn in as Fed Chair on May 22, 2026. Everything
  from that date forward is tagged `Warsh`; everything before is `Powell`.
- **Documents.** Post-meeting statements and meeting minutes (every FOMC meeting, including
  the March–April 2020 intermeeting emergency actions), Chair speeches, Chair congressional
  testimony, and FOMC press conference transcripts. All scraped directly from
  federalreserve.gov — no third-party archive.
- **Tone scoring, two independent methods** (assignment Step 2):
  1. A **custom hawkish/dovish word list** (`data/lexicons/hawkish_dovish_wordlist.csv`),
     built for monetary-policy language in the spirit of Apel & Blix Grimaldi (2012) and
     Correa et al. (2021) — not the Loughran-McDonald general-purpose finance dictionary,
     which has no notion of "hawkish." Score = (hawkish phrase hits − dovish phrase hits)
     per 1,000 words.
  2. **FinBERT** (`ProsusAI/finbert`) sentence-level sentiment, aggregated as
     mean P(positive) − mean P(negative) per document. This is the same method compared
     in "Parsing the Fed" (2021); the report discusses where it agrees and disagrees with
     the word list.
- **Market reaction.** One-day change in each of the four indicators around each release,
  same-day close-to-close (statements/minutes/press conferences are released at 2:00 p.m.
  ET, mid-session; speeches/testimony use the same convention as a documented
  simplification — see `scripts/05_build_dataset.py`).
- **Regression.** Each indicator's one-day change on each tone score, controlling for the
  one-day change in the 3-month T-bill yield (so a tone score isn't credited with the rate
  decision itself), OLS with heteroskedasticity-robust (HC1) standard errors.
